# OpenGamer Studio Page Structure v1.0

Planning document only. Do not treat this as final design or final website copy.

## Global Rules

- Structure must support EN, RU and ES.
- Every page must include `View Portfolio` and `Contact Us` CTAs.
- Portfolio must be the strongest conversion page.
- Keep the site official, clean, technological and readable.
- Casino feeling should be subtle.
- Do not add fake clients, fake certifications, fake metrics or unsupported claims.
- Use short placeholder text until final copywriting starts.
- Do not add heavy animations.

## CTA Model

| CTA | Purpose | Default target |
| --- | --- | --- |
| View Portfolio | Move buyers to the strongest proof/conversion page. | `/portfolio` |
| Contact Us | Convert qualified commercial interest. | `/contact` |

Localized equivalents should use the same intent:

- EN: `/portfolio`, `/contact`
- RU: `/ru/portfolio`, `/ru/contact`
- ES: `/es/portfolio`, `/es/contact`
