# OpenGamer Studio SEO Blueprint v1.0

Planning document only. Meta text below is draft structure, not final marketing copy.

## SEO Rules

- English is the default language.
- Russian and Spanish pages must use hreflang alternates.
- No blog section in v1.0.
- Each main page should work as a landing page.
- Portfolio is the strongest conversion page.
- Do not use fake numbers, fake clients, fake certifications or unsupported claims.
- Use short, clear page intent before final copywriting.

## Hreflang Model

| Language | URL pattern | Hreflang |
| --- | --- | --- |
| English | `/{page}` | `en` |
| Russian | `/ru/{page}` | `ru` |
| Spanish | `/es/{page}` | `es` |

Each localized page should include alternates for `en`, `ru` and `es`.
